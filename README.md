# 📢 MicroInfluencer Project

This repository contains code and labeled datasets for identifying and analyzing micro-influencers on social media platforms. The goal is to apply data-driven techniques to uncover influential users within specific communities or niches.

## 📁 Repository Structure

```
MicroInfluencer/
├── code/                                  # Python scripts for data processing and analysis
├── Label_Sample_1_With_Country_Lang_ID_updated.csv
├── Label_Sample_6_With_Country_Lang_ID_updated_new.csv
├── TopFollowerLabels.csv
└── README.md
```

## 🏁 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/dheeman00/MicroInfluencer.git
cd MicroInfluencer
```

### 2. Install Dependencies
Ensure Python 3 is installed, then run:
```bash
pip install -r requirements.txt
```

### 3. Run Analysis Scripts
Navigate to the `code/` folder and run the analysis scripts. For example:
```bash
cd code
python analyze_influencers.py
```
*(Replace `analyze_influencers.py` with the actual script you want to run.)*

## 📊 Dataset Descriptions

- **Label_Sample_1_With_Country_Lang_ID_updated.csv**:
  Labeled user data including geographic and language metadata.

- **Label_Sample_6_With_Country_Lang_ID_updated_new.csv**:
  Updated version of labeled dataset with expanded attributes.

- **TopFollowerLabels.csv**:
  Metadata on followers identified as having influential status.

## 🎯 Objective

To create scalable and interpretable methods for identifying micro-influencers using real-world data. Potential applications include:
- Targeted marketing
- Influence propagation analysis
- Audience segmentation
